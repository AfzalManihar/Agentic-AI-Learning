# Agentic AI Learning Journey

A hands-on learning repository documenting my journey into **Agentic AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and Multi-Agent Systems**.

This repository contains course notebooks, practical implementations, and experiments exploring how AI agents work, retrieve information, use memory, and interact with LLMs.

## Topics Covered

- Agentic AI Fundamentals
- AI Agents and Agent Architectures
- Memory Systems
- Retrieval-Augmented Generation (RAG)
- Document-Based Question Answering
- Advanced RAG and Retrieval Methods
- Self-RAG
- Multi-Agent Systems
- LLM Evaluation and Guardrails
- Evaluation and Observability

## Repository Structure

- `notebooks/` — Topic-wise Jupyter notebooks containing code, explanations, and practical implementations.
- `My_AI_Agents_original.ipynb` — Original course notebook containing the complete sequence of learning materials.
