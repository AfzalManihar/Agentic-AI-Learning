# Agentic AI Course Notebooks

This repository-ready bundle was created from `My_AI_Agents(6).ipynb`.

## Structure

- `notebooks/` — notebooks split into 14 major topic/date sections.
- `My_AI_Agents_original.ipynb` — untouched original notebook, retained as a backup.

## Important notes

- The split preserves the original cells, including code, Markdown, outputs, and cell metadata.
- Every original cell is included in exactly one split notebook, in its original order.
- Existing dates and topic labels are preserved as written. No missing dates were guessed or added.
- Some notebooks may depend on imports, variables, API keys, packages, or setup cells from earlier parts of the original notebook. If a notebook is run independently, run the required setup cells first and configure secrets/API keys in your environment. Never commit API keys to GitHub.
- The original notebook contains a date written as `27-09-2006`; it has been preserved unchanged rather than silently corrected. Please verify it if needed.

## Suggested GitHub upload

1. Create one GitHub repository, for example `Agentic-AI-Learning`.
2. Upload this folder's contents (or extract the ZIP and upload its contents).
3. Keep `notebooks/` and `My_AI_Agents_original.ipynb` in the repository.
4. In GitHub, open each notebook to check that it renders correctly.
